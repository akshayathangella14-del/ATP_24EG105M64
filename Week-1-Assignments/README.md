# ATP-MERN-Week-1-Assignments

This repository contains the foundational JavaScript assignments for Week 1, focusing on conditional logic, loops, functional programming, and complex array manipulations.

## Day 1: Basic Logic and Functions

The first day focuses on implementing core logic using conditional statements and creating reusable functions for array processing.

### 1.1 Largest of Two Numbers
A script that compares two variables (`a` and `b`) to determine and log which one is the largest.

### 1.2 Largest of Three Numbers
Uses nested if-else conditions to find the maximum value among three different numbers.

### 1.3 Sum of Marks
Calculates the total sum of elements within a numerical array (`marks`) using a for loop.

### 1.4 Finding Minimum Marks
Identifies the smallest element in an array by iterating through the list and comparing each value to a tracking variable.

### 1.5 Function: Largest of Three
A functional approach (`sumOfThree`) that accepts three numerical arguments and returns the largest value among them.

### 1.6 Function: Sum of Array
A reusable function (`sumOfArray`) that takes an array as an argument and returns the total sum of its elements.

### 1.7 Function: Search Element
A search utility (`searchElement`) that iterates through an array to find a specific key, returning its index if found or `"Not Found"` if the element does not exist.

## Day 2: Array Object Manipulations

Day 2 focuses on handling more complex data structures, specifically an array containing employee objects with properties like `eno`, `name`, and `marks`.

### 2.1 Employee Data Management
This script demonstrates how to use the `splice` method to perform various operations on an object array:

- **Insertion**: Adds a new employee object at the second position in the array.  
- **Removal**: Removes a specific employee from the list based on their position.  
- **Updating Nested Data**: Accesses a specific employee's nested `marks` array and modifies a specific value using `splice`.
