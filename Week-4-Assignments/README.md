## Overview

Week 4 marks a shift in the MERN stack curriculum, moving from server-side development (Node.js/Express) and database modeling (Mongoose) toward the browser-side experience.  
The primary goal of these assignments is to master the **HTML5 skeleton** that serves as the foundation for modern web applications and React components.

---

## Day 11: Web Development Fundamentals

The assignments for this day are centered on building structural foundations through three progressive HTML modules located in the `/Day-11/` directory.

### 1.1 Structural Foundations (`1.html`)
This file serves as the introduction to web page architecture, focusing on the **initial scaffolding** required for any web project.

- **Focus**: Basic web page structure and foundational HTML elements.  
- **Implementation**: Utilization of core tags such as `<html>`, `<head>`, and `<body>`, along with content-specific elements like headings (`<h1>`–`<h6>`), paragraphs (`<p>`), and text formatting.  

### 1.2 Advanced Layouts (`2.html`)
Building on the basics, this assignment explores the **spatial organization** of a web page, moving beyond simple text to structured layouts.

- **Focus**: Further structural components and layout design.  
- **Implementation**: Exploring how different elements can be grouped and positioned to create a cohesive user interface, laying the groundwork for future styling with CSS.  

### 1.3 Complex Components (`3.html`)
The final module of the week consolidates the previous lessons by implementing more **sophisticated HTML structures**.

- **Focus**: Foundational frontend development and MERN architecture principles.  
- **Implementation**: Integration of complex components (such as semantic sections, forms, or lists) that are essential for the "View" layer of a MERN application.  

---

## Key Learning Objectives

- **MERN Stack Integration**: Understanding how HTML fits into the broader MERN architecture as the primary delivery method for frontend content.  
- **Semantic Standards**: Learning to use HTML tags that provide meaning and structure to both browsers and search engines.  
- **Frontend Readiness**: Establishing the necessary prerequisites for adding interactivity and dynamic data-binding in upcoming React modules.
